# CLI Box 复合图形

- 记录于 2026-11-25，所属阶段为 Phase 2，任务书 §3、§4

## 需求背景

用户需要批量创建带背景矩形和标题的流程图节点，之后可以移动、嵌套或修改标题。保存的文件还需能在未启用 Box 插件的应用中按普通 SVG 读取。

## 决策记录

| 议题 | 选项 | 决定 | 理由 |
| --- | --- | --- | --- |
| 部件关系 | 普通文档子节点 / 模型私有部件 | 矩形和标题由 Box 持有，普通嵌套成员交给文档 | 通用命令可移动整个 Box，同时保护必要组成。 |
| 编辑入口 | 通用命令按类型分支 / 属性处理器 | 通过 `box-attributes` 调用模型的方法 | 填充、标题及其撤销按插件契约完成。 |
| SVG 读回 | 按 `g` 统一读取 / 带标记恢复 | 带 `data-kind="box"`，按已注册类型恢复 | 已启用时保留语义，未启用时按普通 `g` 读取。 |
| 损坏结构 | 拒绝 / 降级 | 已启用时拒绝候选文档 | 无效私有部件无法形成可编辑的 Box。 |

## 职责边界

Box 插件提供图形类、属性处理器和类型标签；图形类通过 `parts()` 与 `toSvg()` 提供保存时的自身及私有部件写出。文档管理可查询的普通成员、层级与全文档 id 唯一性。SVG 读写通过通用流程处理候选文档和私有部件。 [CLI 扩展契约](20261125_CLI_EXTENSION_CONTRACTS.md) · [装配](20261125_CLI_ASSEMBLY.md)

## Cases 处理策略

| 场景 | 输入或前置状态 | 预期行为 |
| --- | --- | --- |
| 创建和嵌套 | 创建带标题的 Box，或通过 `in` 挂到某个有效容器下 | Box 同时拥有私有矩形、私有标题和普通成员。 |
| 修改或移动 | 设置 `fill`、`label`，执行整体 move 或 scale | 外框、标题按操作更新。整体操作及每次设置各自构成一个撤销单元。 |
| 派生 id 冲突 | 外框或标题的 id 已被现有图形占用 | 创建失败，文档和历史保持原值。 |
| 结构保护 | 直接删除或移走私有部件，或者解组 Box | 私有部件 id 查找失败。解组报告 `cannot ungroup composite shape: <id>`。 |
| 往返与降级 | 保存并读回同一 SVG | 启用 Box 时恢复模型。禁用 Box 且启用基础包时恢复普通 `g`、矩形和文本。 |
| 非法 SVG 结构 | 缺少部件、部件类型错误或出现重复 id | 拒绝读入，原文档、文件路径和历史保持原值。 |

## 接口契约

```text
create box <id> <x> <y> <width> <height> "<标题>" [in <containerId>]
set <id> fill <颜色>
set <id> label "<标题>"
```

新建矩形使用 id `<id>-rect` 和默认填充 `#4a90d9`。标题使用 id `<id>-label`，坐标为 `(x + 20, y + height / 2 + 5)`。写出使用带 `data-kind="box"` 的 `g`，私有部件排在普通成员之前。
