# VS Code 实践说明与演示材料

- 记录于 2026-11-25，所属阶段为 Phase 2，任务书 A.3
- 依赖 [文件标记](20261125_VSCODE_FILE_BADGE.md) 和 [原生大纲](20261125_VSCODE_OUTLINE.md) 的实际实现；已交付，证据见 [VS Code 验收](../../../vscode-extension/docs/acceptance.md)

## 需求背景

验收者需要能从仓库复现实验效果，并理解 VS Code 如何调用扩展。说明材料还要记录文件装饰与两种设计模式的对应关系，以及 Phase 1 代码的复用判断。

## 决策记录

| 议题 | 选项 | 决定 | 理由 |
| --- | --- | --- | --- |
| 演示依据 | 课程参考图 / 本项目真实运行 | 使用本项目截图、示例和测试记录 | 验收者可以对照实际提交复现。 |
| 说明入口 | 分散各处 / 主文档集中导航 | 在 `doc/README.md` 汇总或链接材料 | 源码、步骤、测试与证据可从同一入口定位。 |
| 复用评估 | 只给统一结论 / 逐个比较模块 | 分析 Phase 1 的解析、模型和遍历 | 大纲需要源码位置，领域模型和遍历可能有不同的可复用范围。实际结论随实现验证。 |

## 职责边界

本项收集和说明 A.1、A.2 的成果。分析结合实际代码说明宿主和扩展的职责、注册方式和运行时调用，并用接口与对象组合分析文件装饰和经典 Decorator、Adapter 的对应点与差异。整体验收和发布在总纲的 §7 维护。

## Cases 处理策略

| 场景 | 输入或前置状态 | 预期行为 |
| --- | --- | --- |
| 首次复现 | 验收者从 README 开始 | 能定位源码与示例，按安装和启动步骤在真实扩展环境打开工作区。 |
| 查看展示证据 | 查阅 Explorer 和 Outline 演示 | Explorer 图可辨识标记，Outline 图可关联选中节点与源码位置。 |
| 追踪异常行为 | 依步骤输入不完整 XML 并补齐 | 记录编辑更新、异常输入与恢复的操作和结果，链接相应测试。 |
| 理解实现 | 阅读模式分析和复用评估 | 可定位具体模块与调用关系，并理解各模块是否复用及理由。 |

## 接口契约

文档入口是 `doc/README.md`。交付材料包括扩展源码入口、运行步骤、示例 SVG、两项效果截图、编辑与异常用例证据，以及职责、模式和复用分析。引用应能定位实际实现或测试。
