# 显示命令（tree / show）

- 时间：2026-10-16
- 所属阶段：phase1

## 需求背景

CLI 没有画布，用户只能靠文本掌握文档结构与图形属性。`tree` 以树形内联各图形的核心属性，`show` 给出单个图形及其私有组件的属性明细。参考：refs/phase_1.md §3（显示类）、§5、§6。

## 决策记录

| 议题 | 选项 | 决定 | 理由 |
| --- | --- | --- | --- |
| tree 属性列对齐 | A：同一次输出中，属性列对齐到"最长的连线前缀 + 标签"再加 2 个空格，验收时连续空白视为一个空格；B：标签后固定 2 个空格 | B | 规则简单、输出确定；参考文档的示例本身也未严格对齐，A 无法与全部示例逐字符吻合 |
| tree 内联格式 | A：按类型的专用格式（rect 缩写为 `w=` / `h=`，line 写成 `(x1,y1) -> (x2,y2)`，text 写成 `(x,y) "content"`）；B：统一输出核心属性（该类型 create 的必填参数）的全名 `名=值` | B | 缩写与坐标写法有歧义；所有类型一种格式，属性名与 show、set 一致 |
| tree 内联哪些外观属性 | A：只内联 fill，任何类型设置了即显示，stroke / stroke-width 看 show；B：设置了即全部内联；C：不内联外观属性，只显示核心属性 | C | tree 只显示核心属性，规则单一；全部属性由 show 提供 |
| show 中示例未覆盖的格式 | A：根级图形 `parent=svg`；外观行列出已设置的 fill / stroke / stroke-width，均未设置时省略该行；text 的内容加双引号（`text="…"`）；g 的核心属性行为 `children=<n>` | A | 示例只覆盖 circle |
| 显示标识 | A：统一用模型身份 `<type>#<id>`；B：模型身份 + 文件身份 | B | 复合模型持久化元素名可能不同于 type（Box 写为 g）；tree/show 必须一致，命令回显保留模型名 |
| 复合图形的 show | A：平铺 `fill` / `label` 等属性；B：递归展示私有组件 | B | `label`、`fill` 是 Handler 操作名或部件属性，不是复合模型的真实属性；组件才是真实模型 |
| 组件块的格式 | A：沿用 tree 连线；B：两空格嵌套 | B | 与 show 现有缩进一致；层级由缩进表达，不必重复父节点 |
| 文档成员在 show 中的范围 | A：递归展开；B：只由 tree 展示 | B | show 聚焦模型内部组件；文档结构由 tree 表达 |
| 复合图形的 `children=` | A：有组件时仍计数；B：有组件时省略 | B | 组件已逐行展开，再计数会重复；无组件的普通容器保持 `children=<n>` |

## 职责边界

- 负责：`tree [id]`、`show <id>`。
- 不负责：`help`（归属命令行交互框架）；`canvas` 无参显示（归属文档生命周期与画布）。
- 显示类命令不改变文档，不进入 undo 栈，也不影响 undo/redo 的禁止状态。

## Cases 处理策略

| 场景 | 输入 / 前置状态 | 预期行为 / 输出 |
| --- | --- | --- |
| 正常 | 接口契约 tree 示例中的文档，`tree` | 与该示例一致 |
| 正常 | 同上，`tree markers` | 只输出 markers 子树，首行为 `g#markers` |
| 正常 | 同上，`show c1` | 与接口契约 show 示例一致 |
| 正常 | 复合图形（Box）`show <id>` | 首行为文件标识与父节点，其后递归输出私有组件的属性，不出现复合模型自身的 `fill` / `label` / `children` |
| 正常 | 复合图形含文档成员，`show <id>` | 只展开私有组件；文档成员由 `tree` 展示 |
| 正常 | 普通容器 `show <id>` | 输出 `children=<文档成员数>` |
| 边界 | 空文档 `tree` | 只输出 `svg (<w>x<h>)` |
| 边界 | 空容器 `tree g1` | 只输出 `g#g1` |
| 异常 | id 不存在 | `error: no such shape: r9` |

## 接口契约

**tree**：`tree [id]`

- 全文档首行 `svg (<w>x<h>)`；指定 id 时首行为该图形
- 连线符号：`├── `、`└── `、`│   `、`    `
- 每行 `<显示标识>` 后隔固定 2 个空格内联核心属性，按 create 参数顺序以 `名=值` 输出（名为属性全名，text 的内容加双引号）；不内联外观属性。没有核心属性（g、box）时行尾不留空白
- 显示标识为 `<element>#<id>`：`element()` 返回图形写出的底层 SVG 标签，默认与 `type` 相同；复合模型可覆写（Box 为 `g`）
- 核心属性即该类型 create 的必填参数：

| 类型 | 内联格式 |
| --- | --- |
| rect | `x= y= width= height=` |
| circle | `cx= cy= r=` |
| ellipse | `cx= cy= rx= ry=` |
| line | `x1= y1= x2= y2=` |
| text | `x= y= text="…"` |
| g | 无 |
| box | 无（元素名 `g`，由 `data-kind="box"` 标识模型） |

```text
svg (800x600)
├── rect#bg  x=0 y=0 width=800 height=600
├── text#title  x=20 y=40 text="My Diagram"
└── g#markers
    ├── circle#c1  cx=100 cy=100 r=20
    └── rect#box  x=200 y=80 width=60 height=60
```

**show**：`show <id>`

- 首行 `<显示标识>  parent=<父节点显示标识 | svg>`，显示标识与 tree 相同
- 其后输出该节点的自身属性：核心属性行（格式与 tree 相同）、外观属性行（未设置时省略）
- 节点有私有组件时，逐块递归输出组件的显示信息：组件首行只写 `<显示标识>`，明细再缩进 2 格；此时省略 `children=`
- 节点没有私有组件且是容器时，输出 `children=<文档成员数>`；文档成员本身不递归，由 tree 展示
- 组件块不重复 `parent=`；show 不输出模型类型提示

```text
circle#c1  parent=g#markers
  cx=100 cy=100 r=20
  fill=red
```

```text
g#n1  parent=svg
  rect#n1-rect
    x=120 y=100 width=160 height=60
    fill=#4a90d9
  text#n1-label
    x=140 y=135 text="开始"
```
