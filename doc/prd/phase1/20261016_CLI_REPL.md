# 命令行交互框架（REPL）

- 时间：2026-10-16
- 所属阶段：phase1

## 需求背景

编辑器以 REPL 形式交互：逐行读入命令、解析、分发、输出结果。所有命令共享同一套输入解析与输出约定；命令序列可存成脚本回放，便于演示与验收。

本需求只交付框架：全部命令先以占位形式注册（命令名与语法完整，执行时报"尚未实现"），由后续各命令需求逐个替换为真实实现。参考：refs/phase_1.md §2、§3（命令总表、help）、§6。

## 决策记录

| 议题 | 选项 | 决定 | 理由 |
| --- | --- | --- | --- |
| 需求划分 | A：框架单独成需求，全部命令先占位，由后续需求逐个替换为真实实现；B：框架与首批命令（init / canvas）合为一份需求 | A | 单次交付范围小；命令表与 help 从第一天起完整，框架链路可运行 |
| 占位命令的行为 | A：命令名与语法完整注册（help 可列出），执行时报"尚未实现"；B：未实现的命令按未知命令处理 | A | 与"未知命令"区分开，替换为真实实现时命令表不变 |
| 框架约定的归属 | A：框架机制（分词、分发、报错优先级、参数个数与数字校验、结果 / 警告 / 错误输出、数值格式）由本需求统一提供；具体业务规则（如 id 合法字符）随首个使用者归属；B：全部随首个使用者归属 | A | 机制只实现一处，各命令需求直接使用；业务规则与使用它的命令一同验收 |
| 退出方式 | A：`exit` / `quit` + EOF；B：仅 EOF | A | 交互使用更自然，`help` 中一并列出 |
| 脚本回放（非 TTY 输入）时是否回显命令行 | A：回显 `svg> <原始行>` 再输出结果；B：只输出结果 | A | 输出与交互会话记录同形，可直接对照验收 |
| 多个错误同时成立时报哪条 | A：未知命令 → 无文档 → 参数格式 → 业务校验，只报第一条 | A | 先报最根本的问题 |
| 提示符是否高亮 | A：输出到终端时高亮，重定向时输出纯文本；B：不高亮 | A | 交互时便于区分输入与输出；重定向时保持纯文本，便于对照验收 |

## 职责边界

- 负责：启动横幅、提示符、注释与空行、分词、命令分发、全部命令的占位注册、输出约定（结果 / 警告 / 错误）、数值输出格式、通用参数校验（个数、数字）、报错优先级、`help`、退出、脚本回放。
- 不负责：
  - 各命令的业务语义与真实实现（归属各命令需求，届时替换占位）；
  - "无文档"判定（归属文档生命周期与画布）；
  - id 合法字符（归属图形模型、创建与删除）。

## Cases 处理策略

| 场景 | 输入 / 前置状态 | 预期行为 / 输出 |
| --- | --- | --- |
| 正常 | `npm run cli` | 打印 `svg-editor 0.1 — type 'help' for commands`，随后提示符 `svg>`（后跟一个空格） |
| 正常 | `# comment` 或空行 | 不执行任何操作，状态不变（脚本模式下注释行仅回显） |
| 正常 | `create text t1 20 40 "My Diagram"` | 分词为 `create`、`text`、`t1`、`20`、`40`、`My Diagram`：双引号内为一个参数，引号不计入值 |
| 正常 | `help` | 列出全部命令及语法：init、read、save、canvas、create、delete、move、scale、set、group、ungroup、addto、front、back、tree、show、help、undo、redo、exit、quit |
| 正常 | `exit` / `quit` / EOF（Ctrl+D、脚本结束） | 退出程序 |
| 正常 | `npm run cli < script.txt` | 不打印提示符；每个非空行先回显 `svg> <原始行>`（注释行同样回显），再输出该行结果；结果与手动输入一致 |
| 正常 | 命令产生警告 | 每条警告一行 `warning: <消息>`，先于该命令的结果行输出 |
| 边界 | 数字参数为 `-10`、`0.5` | 负数、浮点合法 |
| 边界 | 输出数值 `130`、`0.1+0.2`、`-0` | 输出 `130`、`0.3`、`0`（整数不带小数点，浮点最多 6 位小数并去掉末尾 0） |
| 边界 | 占位期间执行尚未实现的命令（如 `move r1 10 0`） | 报错：命令尚未实现（与未知命令区分） |
| 异常 | `foo` | 报错：未知命令 |
| 异常 | 参数个数不符 | 报错：参数个数不符，并提示该命令语法 |
| 异常 | 数字参数不是数字（如 `a`） | 报错：参数不是数字 |
| 异常 | `create text t1 0 0 "abc` | 报错：引号未闭合 |
| 异常 | 任一命令执行失败 | 只输出一行 `error: …`，文档状态不变 |

## 接口契约

### 输入

- 启动：`npm run cli`
- 逐行读入；空白分隔参数；双引号包裹的内容为一个参数；`#` 开头的行为注释
- 交互模式（TTY）打印提示符 `svg>`；脚本模式（非 TTY）不打印提示符，改为回显 `svg> <原始行>`
- 输出到支持颜色的终端时，提示符 `svg>`（含回显中的）高亮显示；重定向到文件或管道时不带颜色控制符，文本与上述约定一致
- 退出：`exit`、`quit` 或输入结束（EOF）
- 报错优先级：未知命令 → 无文档 → 参数格式 → 业务校验，只报第一条

### 输出

- 每条一行
  - 成功：编辑类命令回显结果摘要，显示类命令直接输出内容（具体格式由各命令需求定义）
  - 警告：`warning: <消息>`，先于该命令的结果行输出
  - 错误：`error: <消息>`
  - 消息为一句问题描述；需求文档中给出的文案须逐字一致，其余文案实现时自拟
- 数值输出：整数不带小数点；浮点最多 6 位小数，去掉末尾 0；`-0` 输出 `0`
