## 拆分依据

CLI 先固定扩展契约和装配，再分别验收业务插件。统计和目录查看可以独立启停，可以分别验证命令行为。Box 的属性处理、读写和类型标签随其插件交付，接入差异通过两个本地提交复核。树标签另有检查点，覆盖跨插件协作和基础输出兼容。

VS Code 的文件标记与大纲可独立实现和验收，两者通过后汇总真实演示材料。两部分通过各自检查点后进入整体验收和发布。
