# CLI 图形统计

- 记录于 2026-11-25，所属阶段为 Phase 2，任务书 §2.1、§2.3

## 需求背景

用户需要快速了解当前图形的组成。统计要区分内容叶子和结构容器，并把 Box 内部可展示的矩形和标题纳入文档规模。

## 决策记录

| 议题 | 选项 | 决定 | 理由 |
| --- | --- | --- | --- |
| 数据来源 | 节点树 / 只读图形视图 | 遍历 `Document.shapeViews()` | 与树展示共享顺序，覆盖文档成员与私有部件。 |
| 输出顺序 | 类型名排序 / 首次出现排序 | 采用深度优先遍历中的首次出现顺序 | 统计结果与文档遍历顺序对应。 |
| 历史语义 | 编辑 / 查询 | 查询 | 只读取当前文档，执行后可继续撤销上一条编辑。 |

## 职责边界

插件读取当前文档并输出统计。画布根排除在计数之外。每个容器只累计容器数，遍历其成员直至叶子。插件可通过 [装配](20261125_CLI_ASSEMBLY.md) 独立启停。Box 的私有部件由 [Box 插件](20261125_CLI_BOX.md) 提供。

## Cases 处理策略

| 场景 | 输入或前置状态 | 预期行为 |
| --- | --- | --- |
| 混合文档 | 两个容器内外有 3 个矩形、1 个圆、2 个文本，首次出现顺序为矩形、圆、文本 | 输出 `rect: 3  circle: 1  text: 2  (total 6, containers 2)`。 |
| 空容器 | 文档只有一个空分组 | 输出 `(total 0, containers 1)`。 |
| 空文档 | 已 init，未创建图形 | 输出 `(total 0, containers 0)`。 |
| 无文档 | 尚未 init 或 read | 提示先执行 init 或 read。 |
| 参数非法或未装配 | 执行 `stats extra`，或禁用后执行 `stats` | 分别报告命令用法或 `error: unknown command: stats`。 |

## 接口契约

命令为无参数的 `stats`。已装配时进入 `help`。各类型用 `<type>: <count>` 表示，类型计数之间、最后一项与总计之间用两个空格分隔。成功仅输出一行，总计格式为 `(total <leafCount>, containers <containerCount>)`。
