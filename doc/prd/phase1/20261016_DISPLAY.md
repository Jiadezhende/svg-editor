# 显示命令（tree / show）

- 时间：2026-10-16
- 所属阶段：phase1

## 需求背景

CLI 没有画布，用户只能靠文本掌握文档结构与图形属性。`tree` 以树形内联关键几何属性，`show` 给出单个图形的属性明细。参考：refs/phase_1.md §3（显示类）、§5、§6。

## 决策记录

| 议题 | 选项 | 决定 | 理由 |
| --- | --- | --- | --- |
| tree 属性列对齐 | A：同一次输出中，属性列对齐到"最长的连线前缀 + 标签"再加 2 个空格，验收时连续空白视为一个空格；B：标签后固定 2 个空格 | 待定（推荐 A） | A 与接口契约中的示例吻合 |
| tree 内联哪些外观属性 | A：只内联 fill（存在时），stroke / stroke-width 看 show；B：存在即全部内联 | 待定（推荐 A） | tree 保持简洁，完整属性由 show 提供 |
| show 中示例未覆盖的格式 | A：根级图形 `parent=svg`；外观行列出已设置的 fill / stroke / stroke-width，均未设置时省略该行；text 在几何行后追加 `text="…"`；g 的几何行为 `children=<n>` | 待定（推荐 A） | 示例只覆盖 circle |

## 职责边界

- 负责：`tree [id]`、`show <id>`。
- 不负责：`help`（归属命令行交互框架）；`canvas` 无参显示（归属文档生命周期与画布）。
- 显示类命令不改变文档，不进入 undo 栈，也不影响 undo/redo 的禁止状态。

## Cases 处理策略

| 场景 | 输入 / 前置状态 | 预期行为 / 输出 |
| --- | --- | --- |
| 正常 | 接口契约 tree 示例中的文档，`tree` | 与该示例一致 |
| 正常 | 同上，`tree markers` | 只输出 markers 子树，首行为 `g#markers` |
| 正常 | 同上，`show c1` | 与接口契约 show 示例一致 |
| 边界 | 空文档 `tree` | 只输出 `svg (<w>x<h>)` |
| 边界 | 空容器 `tree g1` | 只输出 `g#g1` |
| 异常 | id 不存在 | `error: no such shape: r9` |

## 接口契约

**tree**：`tree [id]`

- 全文档首行 `svg (<w>x<h>)`；指定 id 时首行为该图形
- 连线符号：`├── `、`└── `、`│   `、`    `
- 每行 `<type>#<id>` 后内联属性：

| 类型 | 内联格式 |
| --- | --- |
| rect | `x= y= w= h= [fill=]` |
| circle | `cx= cy= r= [fill=]` |
| ellipse | `cx= cy= rx= ry= [fill=]` |
| line | `(x1,y1) -> (x2,y2)` |
| text | `(x,y) "content"` |
| g | 无 |

```text
svg (800x600)
├── rect#bg        x=0 y=0 w=800 h=600 fill=#ffffff
├── text#title     (20,40) "My Diagram"
└── g#markers
    ├── circle#c1  cx=100 cy=100 r=20 fill=red
    └── rect#box   x=200 y=80 w=60 h=60 fill=#3366ff
```

**show**：`show <id>`

- 首行 `<type>#<id>  parent=<父节点>`；其后每行缩进 2 格，依次为几何属性行、外观属性行

```text
circle#c1  parent=g#markers
  cx=100 cy=100 r=20
  fill=red
```
