# CLI 结构树标签

- 记录于 2026-11-25，所属阶段为 Phase 2，任务书 §5

## 需求背景

用户需要在结构树中看到未保存变化，并识别以 SVG `g` 显示的 Box。多个插件应能独立追加标签，沿用 Phase 1 树布局和输出。

## 决策记录

| 议题 | 选项 | 决定 | 理由 |
| --- | --- | --- | --- |
| 星号语义 | 发生过编辑 / 当前内容与保存基准不同 | 内容比较 | 撤销回保存点时星号可消失。 |
| 变化传播 | 向所有祖先传播 / 标记直接变化与画布 | 行按自身内容、位置和直接成员判断，画布反映整个文档 | 修改子图形属性时可定位具体变化行。 |
| 标签顺序 | 固定类型优先 / 注册顺序 | 按注册顺序追加 | 默认装配中的标签顺序为 `* (box)`，插件各自决定自己的标签。 |

## 职责边界

基础渲染器生成行内容和层级连线。装饰器调用内层渲染，再根据只读视图追加内容。星号的保存基准属于单个装饰器实例。类型标签随 [Box 插件](20261125_CLI_BOX.md) 交付。

## Cases 处理策略

| 场景 | 输入或前置状态 | 预期行为 |
| --- | --- | --- |
| 新建或替换文档 | 成功 init / read | 建立当前基准，画布与行均不标星。 |
| 添加或编辑 | 新增一行、修改子图形属性、调整直接成员或移动图形 | 对应变化行与画布标星。单改子图形属性时其父行保持原样。 |
| 保存、撤销和重做 | 成功保存后再次编辑，再撤销或重做 | 保存时重置基准。撤销回基准后清除星号，重做恢复变化状态。 |
| 组合输出 | 同一个 Box 行满足星号条件 | 默认输出中的行尾为 `* (box)`。 |
| 基础渲染 | 仅启用 core | 无附加标签，Phase 1 的树输出逐字节一致。 |

## 接口契约

现有入口为 `tree [id]`。`TreeDecorator.tag(node, canvas)` 返回当前行标签，空值表示跳过。`onSuccess(event)` 接收 `edit`、`undo`、`redo`、`replace`、`save` 的只读事件，事件携带画布和图形视图。查询及失败命令不会触发成功通知。
