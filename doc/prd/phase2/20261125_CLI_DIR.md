# CLI 当前目录查看

- 记录于 2026-11-25，所属阶段为 Phase 2，任务书 §2.2、§2.3

## 需求背景

用户需要在 CLI 内查看可读写文件所在环境，从而选择路径。目录查看应在文档初始化之前可用，结果与正在编辑哪个 SVG 无关。

## 决策记录

| 议题 | 选项 | 决定 | 理由 |
| --- | --- | --- | --- |
| 查询位置 | 当前 SVG 目录 / 进程工作目录 | 以进程工作目录为准 | read 或 save 后列举目标仍可预测。 |
| 文件系统边界 | 命令直读 / 适配器 | 命令依赖 `DirectoryAccess`，由 `NodeDirectoryAccess` 适配 | 真实文件系统与失败测试使用相同命令逻辑。 |
| 输出分组 | 原始枚举顺序 / 稳定排序 | 目录先于文件，组内按名称升序 | 不依赖目录项枚举顺序和区域设置。 |
| 特殊项 | 解析链接目标 / 按条目自身分类 | 符号链接和其他特殊项标为 `[FILE]` | 只列直接成员。 |

## 职责边界

插件读取工作目录并格式化结果，文档、未保存状态、进程工作目录和撤销重做历史保持原值。通过 [装配](20261125_CLI_ASSEMBLY.md) 独立启停。

## Cases 处理策略

| 场景 | 输入或前置状态 | 预期行为 |
| --- | --- | --- |
| 混合目录项 | 含子目录、普通文件和隐藏文件 | 目录优先，各组按名排序，隐藏项保留，过滤 `.` 与 `..`。 |
| 空目录 | 无可列条目 | 输出 `(empty directory)`。 |
| 读失败 | 文件系统拒绝读取工作目录 | 输出 `error: cannot read directory: <path>`，会话可继续接收命令。 |
| 文档无关 | 尚未 init，或 read 了另一个目录的 SVG | 均列出进程工作目录。 |
| 参数非法或未装配 | 执行 `dir extra`，或禁用后执行 `dir` | 分别报告命令用法或 `error: unknown command: dir`。 |

## 接口契约

`dir` 无参数。已装配时进入 `help`。每个目录项独占一行，前缀为 `[DIR]` 或 `[FILE]`，标记后有两个空格。

`DirectoryAccess` 暴露 `currentDirectory(): string` 和 `read(path): readonly DirectoryEntry[]`。记录包含目录项名称和目录布尔值。代码和配置装配使用同一个命令实现和同一个适配器契约。
