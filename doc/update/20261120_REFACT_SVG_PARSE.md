# 第五批：SVG 编排与模型数据构造

日期：2026-11-20。分三步实施并分别提交：模型数据契约、Reader 复合读回、Writer 校验与整体验收。只使用测试复合模型，不实现正式业务插件。

实现完成，停在第五批验收点。前两步提交为 `62a945a`、`c5cb34e`；第三步提交包含 Writer、完整往返和架构文档。

## 第一步：模型数据契约（已完成）

- Shape.parse(id, attributes, readChildren) 默认复用属性规格解析、默认值及构造校验，返回 ShapeParseResult：shape 和仍应成为文档成员的 children。
- readChildren 由解析器提供，返回已解析的子 Shape；默认叶子不请求，普通容器保留全部成员，特殊模型可消费必要部件并返回剩余成员。模型不接触 XML、ShapeNode 或 Document。
- protected parseValues 供特殊类复用属性解析；Shape.checkId 统一构造与持久化的 id 校验规则。
- ShapeFactory.parse 通过内部类注册表调用可覆写解析能力，create 的已解析属性构造方式不变，definition 不暴露构造或解析函数。

验证：类型检查通过；全量 48 个测试文件、467 个测试通过。测试通过公共入口验证默认解析、叶子不请求递归、容器保留引用和特殊类覆写。

## 第二步：Reader 复合读回（已完成）

- Reader 按已注册 data-kind 优先选择模型，否则回退原标签；不包含具体模型分支。已安装但模型结构无效时传播错误，不降级。
- 模型按需请求子 Shape，Reader 缓存递归结果；返回的 children 必须是输入对象的非重复引用，可重排。消费的对象成为内部部件，其余关系统一加入候选 Document。
- 未消费的普通容器保留完整后代关系；不能将仍带文档子节点的容器静默消费为单个私有 Shape。复合部件自身可通过模型封装内部结构。
- 根及所有输入元素的显式 id 在构造前统一检查，涵盖私有部件和跳过的子树；缺失 id 补号避开所有已存在 id。
- Reader 不再解析领域属性值，默认叶子不请求子元素，普通 SVG 的文本、默认值、错误和输出回归保持通过。

验证：类型检查通过；全量 49 个测试文件、484 个测试通过。公共入口测试复合模型覆盖类型识别、降级、非法部件、混合文档成员、嵌套、缓存、引用契约和 id 冲突。

## 第三步：Writer 校验与整体验收（已完成）

- Writer 先一次性生成完整映射树，检查非法/重复 id、重复 id 属性及 content/children 歧义，再格式化。SaveCommand 的文件写入和路径提交顺序不变。
- 映射生成私有部件，Writer 按序追加节点成员，替代此前直接拒绝混合成员的限制。多映射命中仍拒绝，普通 SVG 输出保持兼容。
- 公共测试复合模型支持私有部件、普通文档成员及嵌套模型，保存读回再次保存逐字一致；整体变换、撤销和树展示通过，不把私有部件变成文档节点。
- 验证未安装类型降级，非法已安装类型读入失败保留文档、路径、节点和历史；输出 id 冲突在文件服务调用前拒绝，文件内容和历史不变。读入不触发 AttributeHandler。
- AGENTS、README 和后续计划已更新；[SVG 读回 ADR](../adr/20261120_SVG_COMPOSITE_PARSE.md)记录数据契约、递归归属、降级及校验边界。

最终验证：npm run typecheck 通过；npm test -- --reporter=dot 通过，50 个测试文件、493 个测试通过；git diff --check 通过。

## 边界与后续

本批只重构架构，不实现正式 Box。模型必须通过 parse 保证私有结构有效，映射必须正确生成私有部件和持久化标记。消费带文档子节点的普通容器会被拒绝，不能静默丢弃后代。

全局校验覆盖输入与输出 SVG，Document 仍只索引文档节点；创建时私有派生 id 的冲突检查是后续创建用例的关联验收项，不能用保存校验替代。第六批树装饰与第七批宿主装配尚未开始。
